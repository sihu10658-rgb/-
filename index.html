🛠️ 설치 방법

단계별 설치 가이드

  1. 레포 클론
    git clone https://github.com/sihu10658-rgb/-
    cd -
  2. Node 의존성 설치
    npm install
  3. 모델 파일 다운로드
    mkdir -p models
    # ggml 모델을 ./models/ggml-model.bin에 배치
  4. .env 파일 생성
    BACKEND=llama
    MODEL_PATH=./models/ggml-model.bin
    PORT=3000
  5. 서버 실행
    npm start

📁 npm install 후 생성되는 파일들

node_modules/ - 모든 npm 라이브러리 (자동 생성)
package-lock.json - 정확한 의존성 버전 정보
models/ggml-model.bin - AI 모델 파일 (직접 다운로드 필요)

💡 중요 정보

node_modules는 매우 크므로 (.bin) 깃에 업로드되지 않습니다. 각 사용자가 npm install로 직접 설치해야 합니다.

🔌 API 사용법

POST /chat

요청:

POST http://localhost:3000/chat
Content-Type: application/json

{"message": "안녕하세요"}

응답:

{"reply": "안녕하세요! 뭘 도와드릴까요?"}

🐳 Docker로 실행

1. Docker 이미지 빌드

docker build -t local-js-chatbot .

2. 컨테이너 실행

docker run -p 3000:3000 --env-file .env -v $(pwd)/models:/app/models local-js-chatbot

ℹ️ 추가 정보

필수 요구사항

  • Node.js 14+ 설치
  • npm 또는 yarn
  • 충분한 저장공간 (모델 파일이 큼)
  • 강력한 CPU/GPU (선택)

모델 옵션

  • Llama (권장): ggml 형식의 양자화 모델 (빠르고 효율적)
  • Xenova: 순수 JS/WASM 백엔드 (추가 빌드 불필요)
